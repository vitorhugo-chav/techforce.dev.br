## 🚀 Sobre o Projeto

Este é o site de portfólio de **Vitor Hugo**, fundador da **TechForce**. O projeto foi desenvolvido para apresentar habilidades, projetos e a trajetória profissional no mundo do desenvolvimento de software. Com um design moderno, responsivo e interativo, o site serve como um cartão de visitas digital, focado em soluções tecnológicas eficientes e modernas.

---

## ✨ Funcionalidades Principais

- **Design Responsivo:** Totalmente adaptável para uma experiência de usuário consistente em desktops, tablets e smartphones.
- **Conteúdo Dinâmico:** As seções de Habilidades, Experiência e Projetos são carregadas dinamicamente a partir de arquivos JSON, facilitando a manutenção e atualização.
- **Navegação Suave:** Animações e transições suaves, incluindo um menu hambúrguer animado para dispositivos móveis.
- **Filtros Interativos:** Permite filtrar os itens nas seções de Experiência e Projetos para uma visualização focada.
- **Carrossel de Projetos:** Em telas menores, os projetos são exibidos em um carrossel automático e interativo.
- **Efeitos Visuais:** Utiliza a biblioteca `particles.js` para um fundo animado e diversas animações em CSS para uma interface mais viva.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

- **Frontend:**

  - **HTML5:** Estrutura semântica do site.
  - **CSS3:** Estilização avançada, com variáveis, Flexbox, Grid e animações.
  - **JavaScript (ES6+):** Manipulação do DOM, interatividade, carregamento de dados (Fetch API) e animações.

- **Bibliotecas:**
  - **particles.js:** Para a criação do fundo com partículas animadas.

---

## 📂 Seções do Site

O site está organizado nas seguintes seções:

1.  **Início (`#hero`):** Apresentação principal com o slogan da TechForce.
2.  **Sobre Mim (`#aboutme`):** Uma breve introdução sobre Vitor Hugo e a TechForce.
3.  **Habilidades (`#skills`):** Exibição das competências técnicas, divididas por categorias (Frontend, Ferramentas, etc.).
4.  **Experiência & Educação (`#experience`):** Uma linha do tempo interativa que mostra a jornada profissional e acadêmica.
5.  **Projetos (`#projects`):** Galeria de projetos desenvolvidos, com links para demonstração e para o repositório no GitHub.
6.  **Contato (`#contact`):** Formulário de contato e links para redes sociais como LinkedIn, GitHub e WhatsApp.

## ⚙️ Como Executar o Projeto

Este projeto é um site estático e não requer um servidor para ser executado. Basta seguir os passos abaixo:

1.  Clone o repositório (ou baixe os arquivos):
    ```bash
    git clone https://github.com/vitorhugo-chav/techforce-portfolio.git
    ```
2.  Navegue até o diretório do projeto:
    ```bash
    cd techforce-portfolio
    ```
3.  Abra o arquivo `index.html` no seu navegador de preferência.

E pronto! O site estará funcionando localmente.
